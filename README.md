# 5GMobile website

Responsive HTML, CSS and JavaScript website with the supplied 5GMobile logo, monthly plan cards, data filters, customer FAQs, an embedded international calling country list and five Broadband Facts disclosures.

## Preview

Run `php -S 127.0.0.1:8081` from this folder, then open http://127.0.0.1:8081/. The optional index.php wrapper prevents stale HTML caching. The static index.html also works on a standard static host.

## Editing

- index.html: homepage copy, navigation and Broadband Facts.
- script.js: plan prices, filters and plan selection.
- styles.css: brand colors, responsive layout and presentation.
- assets/: supplied logo and embedded destination list.

## Content

Plan and destination information follows the requested reference material. Broadband Facts values were transcribed from the supplied screenshots and branded 5GMobile at the owner's request. Verify final plan terms and disclosures before selling service. Add the official 5GMobile terms-of-service URL where indicated.

The website does not process payments or activate service. Google Fonts are optional; system font fallbacks are included. Clipboard access generally requires HTTPS or localhost.

FAQs expanded to 13 consumer questions. Provider-specific support contacts, external payment URLs and portal claims are excluded. Coverage checking, SIM ordering, and payment integrations still need to be connected.
